管理員登入

使用已驗證且獲授權的管理員 Email。房間密碼不能登入後台。

首次建立後，請到信箱驗證 Email，再回來登入。建立帳號不會自動取得管理權限。

TURN 伺服器 A～G

灰：未設定／停用；綠：低於50%；黃：50～95%；紅：超過95%；藍：用量未知／未設額度。黑框代表至少一個頻道目前選用。Metered 約每分鐘更新一次；同帳號的不同憑證共用額度。

記錄搜尋／匯出與清除

更改任一房間密碼會撤銷該房全部登入，包括廣播控制台與工作站。正常連線裝置會在下次同步時退出；員工須使用新密碼重新加入。

伺服器設定

匯入只會上傳至已授權的後台，不會顯示原始金鑰。Metered 使用兩個 TXT；自建或其他服務接受含 urls、username、credential 的 ICE JSON，不需要 Metered 金鑰。其他廠商用量 API 尚未通用，請手動更新用量。

頻道指派與備援

額度達上限且有已設定備援時自動切換；官方用量有延遲，不保證切換前完全不中斷。自建的自動額度切換依手動填入的數值判斷。沒有在線裝置或管理頁查詢時，不會持續輪詢。

登入裝置紀錄

從 v2.4.0 起收集。IP 為請求轉送資訊，可能是 NAT／VPN／代理；裝置欄位由瀏覽器回報，不能當身分證明。有效網速不代表實際 4G 或 Wi-Fi。舊紀錄無法補回。
